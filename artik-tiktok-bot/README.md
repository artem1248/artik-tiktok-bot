# Artik TikTok LIVE Telegram bot

Бот управляется вручную и не проверяет TikTok.

## Переменные окружения в Render
- `BOT_TOKEN` — новый токен от @BotFather
- `ADMIN_ID` — `548699148`
- `GROUP_ID` — `-3757851939`
- `LIVE_URL` — `https://tiktok.com/@artik_sp/live`

Не добавляй токен в GitHub и не отправляй его в чат.

## Запуск
`npm install`, затем `npm start`.

Добавь бота в группу и разреши ему отправлять сообщения. Напиши боту в личные сообщения `/start`.
